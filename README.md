# TaskFlow documentation

A documentation set for **TaskFlow**, a sample task management application. The product is invented; the documentation practice is not.

This repository doubles as a docs-as-code example: Markdown source, Git history, and a Jekyll build published through GitHub Pages.

## Contents

### Product documentation

| Guide | What it covers |
| --- | --- |
| [Getting started](product-docs/getting-started.md) | Creating a first task, from sign-in to assignment. |
| [Recurring tasks](product-docs/recurring-tasks.md) | Repeat schedules, how missed occurrences behave, and editing a series. |
| [Team workspaces](product-docs/team-workspaces.md) | Shared workspaces, roles and permissions, and inviting people. |
| [Integrations](product-docs/integrations.md) | Connecting Slack, Google Calendar, and webhooks. |

### API documentation

| Reference | What it covers |
| --- | --- |

## How this set is written

Second person, present tense, active voice. One term per concept. Every procedure states what it achieves and what you need before you start, and ends with how to check that it worked. Sample requests and responses match the reference.
